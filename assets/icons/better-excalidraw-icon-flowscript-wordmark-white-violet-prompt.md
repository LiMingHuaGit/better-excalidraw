# Icon Prompt Pack

- Style: `flowscript-wordmark`
- Text: `B`
- Palette: `white-violet` (`#FFFFFF` background, `#6965DB` lettering)
- Use case: Chrome extension application and toolbar icon

## Edit Prompt

Edit only the color scheme of the supplied Better Excalidraw icon. Preserve the uppercase cursive `B` monogram geometry, proportions, placement, double-line construction, two underline strokes, padding, bevel depth, and overall composition. Change the entire background to clean white `#FFFFFF`. Change the lettering and underline strokes to brand violet `#6965DB`, with darker violet inline detail and a soft light-violet/gray shadow for separation on white. Keep the exact visible text as one uppercase `B` only. Produce a crisp, polished, high-contrast 1024x1024 opaque RGB icon.

## Negative Prompt

Do not change the monogram shape. Do not add symbols, words, borders, mockup frames, transparency, texture, cropping, or watermarks.

## Output Files

- PNG: `better-excalidraw-icon-flowscript-wordmark-white-violet.png`
- SVG: `better-excalidraw-icon-flowscript-wordmark-white-violet.svg`

## Validation

- PNG is 1024x1024 RGB with no alpha.
- SVG is a self-contained wrapper embedding the approved PNG.
- Rendered text is exactly `B` and remains readable.
- Decorative curves and underline strokes are not cropped.
- No border, mockup frame, extra symbol, or transparent background is present.
