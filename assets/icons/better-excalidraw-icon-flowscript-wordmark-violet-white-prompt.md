# Icon Prompt Pack

- Style: `flowscript-wordmark`
- Text: `B`
- Palette: `violet-white` (`#6965DB` background, white lettering)
- Use case: Chrome extension application and toolbar icon

## Positive Prompt

Create exactly one square 1024x1024 image for a Chrome browser extension app icon. Use a full-bleed solid violet background `#6965DB`. Center one exact uppercase letter "B" only, rendered as a bold elegant flowing cursive monogram with a large decorative capital, highly readable at tiny sizes. Use bright white double-line outlined lettering: a strong white outer stroke with violet inner cutout detail, a subtle restrained bevel, and a soft dark-violet drop shadow. Add two very short, thin white underline strokes directly beneath the B as part of the monogram. Keep generous safe padding and preserve every curve, lower loop, and underline stroke inside the canvas. The result should be a premium polished browser-extension icon with crisp high contrast, RGB color, and no alpha.

## Negative Prompt

Do not misspell or replace the exact uppercase letter "B". No other letters, words, alternate variants, extra symbols, pencils, diamonds, people, mockups, borders, nested rounded app tiles, textures, transparency, or watermarks.

## Output Files

- PNG: `better-excalidraw-icon-flowscript-wordmark-violet-white.png`
- SVG: `better-excalidraw-icon-flowscript-wordmark-violet-white.svg`

## Validation

- PNG is 1024x1024 RGB with no alpha.
- SVG is a self-contained wrapper embedding the approved PNG.
- Rendered text is exactly `B` and remains readable.
- Decorative curves and underline strokes are not cropped.
- No border, mockup frame, extra symbol, or transparent background is present.
