# Better Excalidraw Workspace — Chrome Web Store Listing

## 中文

### 名称

Better Excalidraw Workspace

### 简短说明

把 Excalidraw 变成本地多画布工作区，支持目录管理、快速切换、自动保存和扩展图形。

### 详细说明

Better Excalidraw Workspace 为官方 Excalidraw 网页增加本地项目与多画布管理能力，让零散的绘图文件变成一个可持续维护的工作区。

主要功能：

- 选择电脑上的本地目录作为工作区，递归读取其中的 `.excalidraw` 文件。
- 在侧边栏中搜索、浏览和快速切换多个画布。
- 在当前工作区中新建画布并直接保存为本地文件。
- 切换画布前自动保存，避免正在编辑的内容丢失。
- 支持手动保存和定时自动保存，保存间隔可由用户设置。
- 保存过程中显示状态动画，明确反馈当前操作。
- 支持中文和英文界面，并根据 Chrome/系统语言自动选择。
- 提供基础图形、方向箭头和常用流程图符号。
- 选择扩展图形后，可像原生工具一样在画布上拖拽决定位置和大小。
- 支持对选中图形进行复制、顺/逆时针旋转、水平翻转和垂直翻转。
- 画布文件和目录授权信息仅保存在本地，不上传到开发者服务器。

适合产品设计、流程梳理、架构绘图、教学笔记以及需要管理大量 Excalidraw 文件的用户。

### 权限用途

- `sidePanel`：在 Chrome 侧边栏中展示本地画布工作区。
- `storage`：在本地保存自动保存间隔、最近使用的工作区句柄等设置。
- `https://excalidraw.com/*`：仅在官方 Excalidraw 网站中加载工作区按钮、扩展图形和画布切换功能。

### 单一用途说明

本扩展的唯一用途是增强官方 Excalidraw 网站的本地画布工作区管理和绘图能力。

## English

### Name

Better Excalidraw Workspace

### Short description

Turn Excalidraw into a local multi-canvas workspace with folder management, autosave, fast switching, and extra shapes.

### Detailed description

Better Excalidraw Workspace adds local project and multi-canvas management to the official Excalidraw website, turning separate drawing files into an organized, maintainable workspace.

Key features:

- Choose a local folder as your workspace and recursively discover `.excalidraw` files.
- Search, browse, and switch between multiple canvases from the Chrome side panel.
- Create a new canvas and save it directly into the active workspace.
- Save the current canvas automatically before switching files.
- Use manual saving or configurable timed autosave.
- See a clear loading indicator while saving is in progress.
- Use a Chinese or English interface selected automatically from the Chrome/system language.
- Access additional basic shapes, directional arrows, and common flowchart symbols.
- Draw extended shapes with a native-like crosshair and drag to set their size and position.
- Duplicate, rotate clockwise or counterclockwise, and flip selected shapes horizontally or vertically.
- Canvas files and directory permissions stay on your computer and are not uploaded to a developer server.

Ideal for product design, flowcharts, architecture diagrams, teaching notes, and anyone managing multiple Excalidraw files.

### Permission justification

- `sidePanel`: Displays the local canvas workspace in Chrome's side panel.
- `storage`: Stores local preferences such as the autosave interval and the most recently used workspace handle.
- `https://excalidraw.com/*`: Runs workspace controls, extended shapes, and canvas switching only on the official Excalidraw website.

### Single-purpose statement

The extension's single purpose is to enhance the official Excalidraw website with local canvas workspace management and drawing tools.
