# Chrome Web Store Upload Checklist / 上传清单

- [ ] Upload `release/better-excalidraw-workspace-0.7.0.zip`.
- [ ] Confirm the package contains `manifest.json` at the ZIP root.
- [ ] Upload `public/icons/icon128.png` as the 128×128 store icon.
- [ ] Upload 1–5 screenshots from `store-listing/screenshots/` in their numbered order.
- [ ] Paste the localized Chinese and English copy from `STORE_LISTING.md`.
- [ ] Select Productivity as the category.
- [ ] Add a publicly accessible URL for `PRIVACY_POLICY.md` if the dashboard requests one.
- [ ] Declare that user data is handled locally and is not sold or used for unrelated purposes.
- [ ] Verify `sidePanel`, `storage`, and `https://excalidraw.com/*` against the permission explanations.
- [ ] Test the final unpacked `dist/` build before submitting for review.

Official screenshot specification: 1280×800 or 640×400, square corners, no padding; up to five screenshots.
