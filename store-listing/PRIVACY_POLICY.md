# Better Excalidraw Workspace Privacy Policy / 隐私政策

Last updated / 最后更新：2026-10-30

## 中文

Better Excalidraw Workspace 不收集、出售或向开发者服务器传输个人数据。

- 用户选择的工作区目录、画布文件内容和图片数据仅在用户电脑本地读取和写入。
- 扩展设置（例如自动保存间隔和最近使用的目录句柄）仅保存在 Chrome 本地存储或浏览器本地数据库中。
- 扩展不会使用分析、广告、跟踪或遥测服务。
- 扩展仅在 `https://excalidraw.com/` 上运行内容脚本，以提供用户主动安装后启用的工作区和绘图功能。
- 用户可随时在 Chrome 中卸载扩展，并通过 Chrome 网站设置撤销目录权限。

如未来版本引入任何数据收集或外部服务，本政策会在发布前更新，并在 Chrome Web Store 中明确披露。

## English

Better Excalidraw Workspace does not collect, sell, or transmit personal data to a developer-operated server.

- Workspace folders, canvas contents, and embedded image data are read from and written to the user's computer only.
- Extension preferences, such as the autosave interval and the most recently used directory handle, are stored only in Chrome local storage or browser-local databases.
- The extension does not use analytics, advertising, tracking, or telemetry services.
- The content script runs only on `https://excalidraw.com/` to provide the workspace and drawing features enabled by the user's installation.
- Users can uninstall the extension at any time and revoke directory permissions through Chrome site settings.

If a future release introduces data collection or an external service, this policy will be updated before release and clearly disclosed in the Chrome Web Store listing.
